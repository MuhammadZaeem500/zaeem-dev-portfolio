# Content Update Checklist

## When adding experience

-   Update Experience data.
-   Check date formatting and location.
-   Keep technology names consistently capitalized.
-   Update About claims if experience count changes.

## When adding a project

-   Add card data.
-   Add detail data with matching id.
-   Add optimized public image.
-   Verify modal on mobile/desktop.
-   Add a project note to this vault.

## When changing contact details

Update Contact and Footer/social links as needed, then test every
external link.

## When changing resume

Replace `public/CV.pdf`, verify download, and confirm the resume content
matches the portfolio.

## Before release

Run \[\[10 - Development/Testing Strategy\]\] and \[\[11 -
Deployment/Deployment Guide\]\].
