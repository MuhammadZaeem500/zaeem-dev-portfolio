# `src/app/layout.tsx`

## Responsibility

Root layout for every route.

## Key behavior

-   Imports Next.js `Metadata`.
-   Loads `Space_Grotesk` using `next/font/google` with weights
    300--700.
-   Imports `@/app/globals.css`.
-   Sets metadata title to `Muhammad Zaeem - Front End Developer`.
-   Sets description to `Generated by Muhammad Zaeem`.
-   Applies the generated font class to `<body>`.
-   Uses `<html lang="en" suppressHydrationWarning>`.

## Improvement notes

The metadata description should be more descriptive for SEO, e.g. a
concise summary of the developer, stack and portfolio.
`suppressHydrationWarning` should only remain if a known hydration
mismatch requires it.
