# HeroSection

**File:** `src/components/HeroSection.tsx`\
**Anchor:** `#home`

## Purpose

First-screen introduction and primary calls to action.

## Main message

Positions the portfolio around responsive modern web apps with React and
Next.js.

## CTAs

-   `View My Work` → `#projects`
-   `Contact Me` → `#contact`

## Animation

Framer Motion animates the heading, paragraph and CTA group from
horizontal offsets into view with opacity transitions.

## Layout

Full viewport minimum height, centered content, responsive heading sizes
and a stacked-to-horizontal CTA layout.
