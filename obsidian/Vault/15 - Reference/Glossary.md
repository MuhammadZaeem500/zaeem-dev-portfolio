# Glossary

**App Router** --- Next.js routing system based on the `app/`
directory.\
**Client Component** --- component marked with `"use client"` and
allowed to use client-side hooks/browser behavior.\
**Server Component** --- default App Router component model rendered
without client JavaScript unless needed by descendants.\
**Framer Motion** --- animation library used throughout the portfolio.\
**EmailJS** --- email service used by the contact form.\
**MOC** --- Map of Content; an Obsidian index note linking related
notes.\
**RBAC** --- role-based access control, mentioned in project case-study
content.\
**Prisma** --- ORM represented in full-stack project descriptions.\
**Tailwind CSS** --- utility-first CSS framework used by the portfolio
UI.\
**ADR** --- Architecture Decision Record; a note documenting a technical
decision and its reasoning.
