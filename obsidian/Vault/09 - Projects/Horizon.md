# Horizon

## Summary

Multi-page information application about the Saudi passport, visa
requirements and citizenship guidance. Uses structured utilities, hooks,
optimized imagery, responsive design and animations.

## Stack represented in source

Next.js, Tailwind CSS, React Hooks, React Icons, Framer Motion, utility
data, Vercel.
