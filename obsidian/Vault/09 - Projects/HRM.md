# HRM

## Summary

Office/HR management application for attendance, leave, projects,
payroll and employee records. Detail content covers task tracking,
project tracking, secure payroll data, reusable UI, responsive design
and deployment.

## Stack represented in source

React.js, MUI, Redux, TypeScript, JavaScript, NestJS, PostgreSQL,
Prisma, authentication/RBAC, Vercel.
