# Project Overview

## Purpose

The portfolio is a professional web presence for Muhammad Zaeem. Its
purpose is to communicate front-end/full-stack capability, show selected
projects, summarize experience, provide a downloadable resume and create
a direct contact path.

## Primary user journey

1.  Visitor lands on the hero section.
2.  Visitor understands the developer's positioning and core stack.
3.  Visitor reads the About and Skills sections.
4.  Visitor explores featured projects and opens project-detail modals.
5.  Visitor reviews professional experience.
6.  Visitor sends a message or follows social links.
7.  Visitor can download the resume from the navbar/footer.

## Current positioning in the UI

The hero describes the owner as a Front-End Developer focused on
responsive modern web apps using React and Next.js. The About section
emphasizes React, Next.js, Redux, Tailwind CSS and MUI, scalable
front-end architecture and backend integration.

## Design direction

The site uses a dark visual system, large headings, alternating
black/gray sections, compact pill labels, responsive layouts,
scroll-triggered animation and a fixed translucent navbar.
