# Muhammad Zaeem Portfolio --- Obsidian Vault

This vault documents the current portfolio source tree in `src(2).zip`.
It is designed to be opened directly as an Obsidian vault and to remain
useful as the project grows.

Start at \[\[00 - Home/Portfolio Dashboard\]\].

## What this vault covers

-   Current `src/` architecture and file responsibilities
-   Page composition and section flow
-   Every current React component
-   Project and experience data
-   EmailJS contact flow and API route
-   TypeScript types and global declarations
-   Tailwind/global styling and animation approach
-   Assets and environment-variable expectations
-   Development, testing, deployment, maintenance and Git workflow
-   Known issues, technical debt and recommended improvements
-   A roadmap and reusable documentation templates

> Scope note: the uploaded archive contains only `src/`, so package
> versions, root configuration files, `public/` contents and deployment
> settings cannot be verified from the archive itself. Where they are
> discussed, the vault clearly marks them as inferred or expected.
